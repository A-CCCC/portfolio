Photos for the Backup Camera Wiper page.

The start of the filename says which section a photo belongs to; within a
section they run in filename order:

    problem-01.jpg     -> The Problem (a section with none reads as a statement)
    solution-01.jpg    -> The Solution, beside its paragraph
    start-01.jpg       -> The Process: Starting the Project
    early-01.jpg       -> The Process: Early Steps
    challenge-01.jpg   -> The Process: Challenges
    final-01.jpg       -> The Process: Final Product

Anything ending .jpg .jpeg .png or .webp is picked up; restart the dev server
or rebuild after adding files. The scrubbed footage is separate — it lives in
public/backup-camera-wiper-outside-anim/ and public/backup-camera-wiper-anim/,
made from video by scripts/make-scroll-frames.py.
